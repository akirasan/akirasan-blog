Ya se que no es ninguna novedad, pero he encontrado interesante hacer una mención en el blog. Para todos aquellos que no lo sepáis una aplicación portable es aquella que no requiere una instalación como tal, es decir, que simplemente te la bajas y le dices donde quieres descomprimirla y ya está, ya puedes utilizarla. Estas aplicaciones cada vez están teniendo mas repercusión ya que con la evolución de los sistemas de almacenamiento USB, que cada vez tienen mas capacidad, y permite llevarte a donde quieras tus aplicaciones (portables).

Uno de los mejores sitios web donde podréis un gran surtido de estas aplicaciones es en [PortableApps.com](http://portableapps.com/ "http://portableapps.com/") donde hay un buen set de aplicaciones de este tipo que puedes descargar gratuitamente y utilizar desde una memoria USB o disco portable. Vamos que puedes encontrar desde: el editor grafico GIMP, OpenOffice, el gestor de correo Thunderbird, el navegador Firefox 2.0, clientes FTP's, servidor web, etc,etc,...
