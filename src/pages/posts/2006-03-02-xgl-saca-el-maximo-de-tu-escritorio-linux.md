Encuentro en [noticias.com](http://www.noticias.com/articulo/25-02-2006/guillem-alsina/xgl-potencia-grafica-tu-escritorio-linux-al-maximo-53bk.html) una noticia interesante sobre ese gran SO,...Linux.

> Un servidor gráfico que aprovecha al máximo los recursos de las nuevas tarjetas de vídeo gracias a la arquitectura OpenGL está empezando a hacer furor entre la comunidad linuxera.
>
> Xgl consiste en una arquitectura de servidor gráfico que utiliza la API OpenGL para sacar el máximo provecho de las tarjetas gráficas de nueva generación, especialmente los "monstruos" orientados a los jugadores más exigentes que están lanzando empresas como ATI o Nvidia.
>
> Las funcionalidades que este servidor permite a un sistema Linux van desde la transparencia de ventanas hasta la posibilidad de rotar el escritorio en un entorno puramente 3D para cambiar de usuario o de escritorio virtual. Son las funciones que proporciona por ejemplo el sistema operativo de Apple, Mac OS X.
>
> La "fama" le llegó a esta arquitectura cuando hace unos días Novell mostró una serie de capturas de pantalla y películas donde se veía su próxima distribución de Linux para máquinas desktop, en la cual se hace uso de Xgl para conseguir unos efectos visuales impactantes. Ahora, varias distribuciones van a incluir Xgl de una u otra forma: Ubuntu (gracias a la implementación realizada por Novell), y OpenSuSE, la "hermana" libre de SuSE Linux.
