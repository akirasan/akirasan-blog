![gmail_mobile.png](http://www.akirasan.net/uploads/2006_2/11/gmail_mobile.png "gmail_mobile.png")Gmail a lanzado un aplicación basada en java para tu teléfono móvil. Desde esta aplicación podrá consultar y contestar tu correo @gmail. En teoría desde GMail Mobile puedes hacer casi todas las funcionalidades que haces desde el PC en tu cuenta de GMail. Todos los mails que envías y recibes se sincronizan. Para instalar la aplicación tenéis que acceder desde vuestro teléfono móvil a la dirección [http://www.gmail.com/app](http://www.gmail.com/app "http://www.gmail.com/app").
