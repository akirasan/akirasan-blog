Como siempre vía [genbeta.com](http://www.genbeta.com/2006/11/17-talkonaut-google-talk-en-tu-movil "http://www.genbeta.com/2006/11/17-talkonaut-google-talk-en-tu-movil") encuentro las mejores utilidades, ahora esta: [**Talkonaut**](http://www.talkonaut.com/ "http://www.talkonaut.com/"). Se trata de un GTalk para el móvil, pero esta vez **no es oficial** de Google, como lo era el [GMail para movil](http://www.genbeta.com/2006/11/02-correo-gmail-en-tu-movil "http://www.genbeta.com/2006/11/02-correo-gmail-en-tu-movil") (por cierto en mi SonyEricsson Z520i funciona de maravilla).

> **Talkonaut** es un cliente de **Google Talk** que nos permitirá tener nuestra lista de contactos, gestionarla y comunicarnos con las personas que tengamos online desde nuestro teléfono móvil, siempre que sea compatible con Java (J2ME).
