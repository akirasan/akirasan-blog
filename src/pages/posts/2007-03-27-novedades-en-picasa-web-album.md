Como hace tiempo que estoy algo desactualizado,...poniéndome al día he visto que **Picasa Web Album** ha liberado un par de temas muy interesantes:

* Para empezar ya se pueden hacer públicas nuestras galerías de fotos al resto del mundo. Ya, ya,...ya se que las galerías podían ser públicas, pero ahora son mas públicas, es decir, que son indexadas por un servicio llamado “*[Community Photos](http://www.akirasan.net/uploads/2007/03/picasawebalbum_1.jpg)*”. Eso quiere decir que podemos buscar fotos dentro de los álbumes de otros usuarios de Picasa Web Album.
* Y el otro servicio es [Picasa Web Albums se añade a la API de Google](http://code.google.com/apis/picasaweb/overview.html "http://code.google.com/apis/picasaweb/overview.html ") (formato **GData**) que permitirá a aplicaciones externas acceder a la información y mantener los albums, fotos, comentarios, etc, que tengamos en nuestra cuenta de usuario. Para que os habáis una idea tenemos [Picnik](http://www.picnik.com/ "http://www.picnik.com/"), una aplicación online que permite, sin descargarte nada, editar tus fotos y ahora gracias a la API las de Picasa Web Album (por cierto el **Picnik**, está tremendo!!!).
