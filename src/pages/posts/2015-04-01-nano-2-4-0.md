Si eres uno como yo que pasa del `vi` como editor de texto y utilizas [nano](http://www.nano-editor.org/), que sepas que a liberado su versión 2.4.0 (una nueva versión desde no se cuanto tiempo hace,...bueno si, mas de cuatro años que me documentado ;) ). La [lista de cambios](http://www.nano-editor.org/dist/v2.4/ChangeLog) es bastante extensa e incluye mejoras como: Undo, bloqueo de ficheros cuando se está editando, nuevo formateo de código para cuando estás programando reconociendo diferentes lenguajes,...

Si eres *"un agonías"* y no puedes esperar a que llegue la nueva versión liberada en los diferentes repositorios de las distribuciones linux, se puede instalar de forma manual con la liberación del código.

Pasos a seguir (desde un terminal y aconsejable como root, aunque no es necesario hasta el paso donde hacemos el install):

Descargamos las dependencias de nano para poder compilarlo:

```auto
sudo apt-get build-dep nano
```

Nos descargamos la versión src:

```auto
wget http://www.nano-editor.org/dist/v2.4/nano-2.4.0.tar.gz
```

**Nota:** si durante la compilación surge algún problema, se ha liberado recientemente una versión 2.4.1pre que soluciona el tema: <http://www.nano-editor.org/dist/test/nano-2.4.1pre1.tar.gz>

Descomprimimos el contenido:

```auto
tar -xzvf nano-2.4.0.tar.gz
cd nano-2.4.0
```

Ejecutamos el script de configuración para la compilación del código:

```auto
./configure --prefix=$HOME/usr
```

Y los dos últimos pasos: compilar e instalar

```auto
make
make install
```

Por último, podemos borrar el fichero descargado y el directorio:

```auto
rm -r nano-2.4.0.tar.gz nano-2.4.0
```

Para verificar que lo tienes instalado, puedes ejecutarlo y poner desde la línea de comandos: `nano --version`
