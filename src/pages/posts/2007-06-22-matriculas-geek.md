Como alguno de vosotros ya sabéis, estoy pendiente de recibir [mi C4 Picasso](http://www.akirasan.net/?p=361 "http://www.akirasan.net/?p=361"). Hoy me he fijado en las matriculas mas nuevas, para ver que letras me tocarían. La mas nueva ha sido una nnnn FRR. Y me ha dado que pensar,..."si ya van por la FRR y a mí aun **me quedan dos semanas** (si no hay mas cambios, porque se están luciendo los de Citröen), es posible que me toque la FTP!!!!". Si ya lo sé, sería una [frikada](http://es.wikipedia.org/wiki/Friki "frikada"), pero mas sería si además el número de matricula fuera: 0021 FTP. Eso sería la reostia!!!,...jejeje. Pero esto no acaba ahí porque le he dado vueltas al tema,...y ¿cuales serían las combinaciones mas [Geek](http://es.wikipedia.org/wiki/Geeks "geek") de las matrículas españolas? (para aquellos que no sepáis como funcionan [os dejo un enlace a la wikipedia](http://es.wikipedia.org/wiki/Matr%C3%ADcula_%28autom%C3%B3viles%29#Espa.C3.B1a "os dejo un enlace a la wikipedia"), donde lo explican muy bien,...), las que se me han ocurrido han sido estas:

* Existen coches ya matriculados
  + nnnn **BPS**: El coche que corre a nnnn Bits Por Segundo, aquí lo ideal un: 1024, 0512, 0256, 0128,...ya me entendéis
  + nnnn **BBS**: El coche BulletinBoard (para los mas jovencitos [definición de BBS](http://es.wikipedia.org/wiki/BBS "definición de BBS") )
  + nnnn **DBF**: dBaseCar
  + nnnn **DLL:** Windows Library Car
  + nnnn **DMZ**: El coche desmilitarizado
  + nnnn **DVD**: La mejor imagen
  + nnnn **DSL**: Coche con Linea Digital
  + nnnn **CSV**: Separado por ;
  + nnnn **CRC**: El coche con código redundante
  + nnnn **CSS**: Coche con estilo propio
  + nnnn **CPD**: Conche con un Centro de Proceso de Datos
  + nnnn **CRT**: ScreenCar obsoleto (ver ScreenCar con LCD ;P)
  + nnnn **CMD**: MS-DOS CommandCar
* Futuras matrículas
  + nnnn **FTP**: El coche "Transport Protocol" (con numeración 0021 FTP, ya sería suerte!!!).
  + nnnn **HTM**: Un PageCar
  + nnnn **WWW**: Un WebCar
  + nnnn **XML**: El TagCar
  + nnnn **RSS**: El SyndicationCar
  + nnnn **SDK**: El coche con Kit de desarrollo propio
  + nnnn **JPG**: Coche con imagen
  + nnnn **PNG**: Otro coche con imagen
  + nnnn **PHP**: Coche con código
  + nnnn **JSP**: Otro coche con código, pero Java
  + nnnn **PDF**: DocumentCar
  + nnnn **XLS**: ExcelCar
  + nnnn **RFC**: Coche con conexión remota
  + nnnn **TXT**: Coche con formato texto
  + nnnn **SQL**: QueryCar
  + nnnn **LCD**: ScreenCar
  + nnnn **MMC**: MemoryCar
  + nnnn **PLC**: Conche con Controlador Lógico Programable
  + nnnn **LSB**: Conche con Linux Base
  + nnnn **RPM**: PackageCar para Linux
  + nnnn **ZFS**: FileSystemCar (tan de moda últimamente).
  + nnnn **SFS**: FileSystemCar Seguro
  + nnnn **RTF**: Otro DocumentCar

Como veis la gran mayoría de las que se me han ocurrido son matrículas futuras,...va a ser divertido.
