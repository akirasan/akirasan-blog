[ipify](http://www.ipify.org/) es un servicio muy simple para conocer nuestra IP pública mediante una API que podemos llamar desde diferentes lenguajes:

* Bash
* Python
* Ruby
* NodeJS
* Javascript
* jQuery

¿En que lo diferencia de otros servicios de este estilo?, pues estas son las ventajas:

* Se puede utilizar de forma ilimitada sin restricción
* Tiene una alta disponibilidad
* Trabaja tanto con IPv4 como IPv6
* Es OpenSource, tiene publicado su código en [GitHub repository](https://github.com/rdegges/ipify-api))
* Nos puede dar el resultado en formato texto plano, json, jsonp sin necesidad de recortar el resultado de la llamada.
