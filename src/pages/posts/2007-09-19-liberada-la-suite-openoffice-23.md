![](http://www.openoffice.org/branding/images/logonew.gif)La nueva versión de la suite ofimática [OpenOffice 2.3](http://www.openoffice.org/index.html "http://www.openoffice.org/index.html") ya está disponible. Para quien no sepa que es OpenOffice, es muy sencillo: es como el Microsoft Office, pero gratis,...dispone de editor de texto ([Writer](http://www.openoffice.org/product/writer.html "http://www.openoffice.org/product/writer.html")), hoja de cálculo ([Calc](http://www.openoffice.org/product/calc.html "http://www.openoffice.org/product/calc.html")), base de datos ([Base](http://www.openoffice.org/product/base.html "http://www.openoffice.org/product/base.html")), presentaciones ([Impress](http://www.openoffice.org/product/impress.html "http://www.openoffice.org/product/impress.html")), editor de diagramas ([Draw](http://www.openoffice.org/product/draw.html "http://www.openoffice.org/product/draw.html")) y un editor de fórmulas matemáticas ([Math](http://www.openoffice.org/product/math.html "http://www.openoffice.org/product/math.html")), todo este paquete gratis y para las plataformas Linux, Apple y Windows.

Y para aquellos que quieran conocer mas este producto y les quede cerca Barcelona, durante los días del 19 al 21 de septiembre se celebra la [OOoCon 2007](http://marketing.openoffice.org/ooocon2007/ "http://marketing.openoffice.org/ooocon2007/") (OpenOffice.org Conference 2007)
