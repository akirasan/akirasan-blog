Esta gente de Microsoft no tiene otra cosa que sacar un formato de imagen “*mejor*” que el mundialmente conocido y utilizado JPEG. El nuevo formato bautizado como [Windows Media Photo](http://www.microsoft.com/whdc/xps/wmphoto.mspx "http://www.microsoft.com/whdc/xps/wmphoto.mspx ") (*wmp*) será soportado por el Windows Vista, y se tiene previsto también para Windows XP. Bill Crow, *Program Manager* del Windows Media Photo, comentó esto en una presentación (Vía [CNET News Article](http://news.com.com/2100-1025_3-6076650.html?part=rss&tag=6076650&subj=news "http://news.com.com/2100-1025_3-6076650.html?part=rss&tag=6076650&subj=news")):

> In his presentation, Crow showed an image with 24:1 compression that visibly contained more detail in the Windows Media Photo format than the JPEG and JPEG 2000 formats compressed at the same level. Still, the image in the Microsoft format was somewhat distorted because of the high compression level.
>
> Typically digital cameras today use 6:1 compression, Crow said. Windows Media Photo should offer better pictures at double that level, he said. "We can do it in half the size of a [tag]JPEG[/tag] file."

  
Vamos que una imagen comprimida a **24:1** en [wmphoto](http://en.wikipedia.org/wiki/Windows_Media_Photo "http://en.wikipedia.org/wiki/Windows_Media_Photo") tiene **mejor detalle** que una comprimida en JPEG o JPEG2000 con el mismo ratio. Además la compresión **6:1** que hacen las camaras digitales se puede **aumentar el doble**, c**on mejor calidad**,...madre mia!!!,... espero que Nikon y las otras compañías saquen un firmware para actualizar la cámara,...
