Como podéis ver el aspecto del blog a cambiado un poco, no mucho,...Por fin he encontrado un theme para Wordpress que vale la pena, es el [Tarski](http://ionfish.co.uk/tarski/ "tarski"). Además tiene bastantes opciones para configurarlo a tu gusto e incluso se puede utilizar un CSS propio que complementa al estandar, esto es ideal para personalizarlo!!!. También soporta widgets y viene preparado para aceptar algunos plugin's.
