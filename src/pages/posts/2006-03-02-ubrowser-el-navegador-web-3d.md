> (***[noticias.com](http://www.noticias.com/articulo/01-03-2006/guillem-alsina/ubrowser-navegador-web-3d-53g1.html "noticias.com")***) El nuevo uBrowser es un navegador innovador y rompedor por la forma en que trata gráficamente las páginas web. Basado en el motor de renderización Gecko (el mismo que equipa a Firefox), utiliza la API gráfica OpenGL para permitir al usuario realizar operaciones tan espectaculares con las páginas web como rotarlas, acercarlas a la vista ampliando una pequeña parte de la página, o alejarla.
>
> Por el momento, este navegador aún se muestra lento en máquinas sin una tarjeta gráfica con cierta potencia, además de que su interfaz de usuario es algo tosca y poco trabajada, pero lo novedoso de la idea y las tendencias que están siguiendo los sistemas operativos de mostrar interfaces de usuario no sólo con efectos 3D, si no totalmente tridimensionales, hace de este un proyecto con cierto futuro.
